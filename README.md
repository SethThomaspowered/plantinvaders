# Plant Invaders
Project to identify and route out invasive plant species. 

Give people tools to identify exotic invasive plant species where they live. 
Possible applications:
  Create a reporting system that allows people to take photos of invasive plants found in their community and provide locate for plants to be dealt with.
  Create a matching game where people try to find all of the plant invaders. 
  Create t-shirts or posters with invasive species.
